# sensor-monitoring-system-with-lcd-display
A sensor monitoring system is an electronic setup designed to continuously track environmental parameters such as temperature, light, humidity, or motion using sensors, and respond when certain conditions are met.  
Build using Tinkercad Circuits.
A sensor monitoring system is an electronic setup designed to continuously track environmental parameters such as temperature, light, humidity, or motion using sensors, and respond when certain conditions are met. In this project, the system uses a TMP36 temperature sensor and an LDR (light-dependent resistor) to measure temperature and light levels. The values are displayed on a 16×2 LCD screen in real time, allowing users to easily observe environmental changes. A threshold mechanism is implemented so that when the temperature exceeds a set value or the light level drops below a certain limit, an LED indicator is activated as an alert. This kind of system is widely applicable in smart homes, greenhouses, weather stations, and industrial monitoring, where real-time awareness and automatic responses to changing conditions are essential. By simulating in Tinkercad, students and beginners can experiment with wiring, code, and logic without the risk of damaging real components making it an excellent platform for learning how monitoring systems work in real-world applications.
